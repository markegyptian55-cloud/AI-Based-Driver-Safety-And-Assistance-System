Observed issue — verified timeline from results.csv (all 77 rows read, not
sampled from chat-pasted excerpts):
  Epoch 1:        mAP50=0.489  mAP50-95=0.216  (cold start)
  Epoch 1-52:     steady, mostly monotonic climb
  Epoch 52:       mAP50-95 peak (0.53175) -> this is best.pt
  Epoch 52-58:    plateau, mAP50 still inching up to its own peak at epoch 58
                  (0.87252) while mAP50-95 is flat-to-slightly-down
  Epoch 58-73:    decline. mAP50 0.87252 -> 0.78067 (trough at epoch 73).
                  mAP50-95 0.53157 -> 0.4683. Precision 0.762 -> 0.681.
                  Recall HELD/rose slightly (0.808 -> 0.818) throughout.
  Epoch 73-77:    recovery, without any config change. mAP50 0.78067 ->
                  0.86164, mAP50-95 0.4683 -> 0.52321 by epoch 77.
  Run stopped manually after epoch 77 (no epoch 78 row in results.csv, no
  training process running, results.csv/last.pt both timestamp the same
  moment as the stop).

Root cause (evidence-based, not fabricated — see BOOK.md Chapter 3 SS3.1.1
for the full column-by-column reasoning):
During the epoch 58-73 decline: train/cls_loss kept falling smoothly the
entire time (0.72266 -> 0.67955, monotonic) while val/cls_loss ROSE sharply
(0.70926 -> 0.84676, +19%) and val precision/mAP fell. Train/box_loss and
val/box_loss both stayed flat-to-improving throughout — box regression was
never the problem, classification confidence/calibration was. Train-loss-down
+ val-loss-up simultaneously is the textbook definition of overfitting, and
that signature IS present here for the classification head specifically.
HOWEVER: it self-reversed by epoch 77 with no config change, which classic/
permanent overfitting does not typically do on its own. Best-supported
conclusion: a temporary widening of the train/val generalization gap on the
classification head, self-corrected before the run was stopped — evidence
fits an overfitting-like signature better than pure optimizer/LR instability
(LR itself was smoothly decreasing per the cos_lr schedule the whole time,
no spike), but the spontaneous recovery means it should not be called
settled, permanent overfitting either. Root cause is not fully conclusive
beyond this.
